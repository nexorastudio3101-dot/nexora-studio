# NEXORA Studio

Static zero-cost prototype for the NEXORA Studio website.

## Run locally
Open `index.html` in a browser.

## Publish for €0
Upload this folder to a GitHub repository and enable GitHub Pages, or deploy the repository to a free static hosting service.

## Important
The course purchase links are intentionally empty. When `purchaseLink` is empty, the course page shows "NOTIFY ME WHEN IT OPENS". When you add a URL to `purchaseLink`, it automatically changes to "BUY NOW".

The current notification form is a front-end prototype using localStorage only. For real email notifications, connect the form to a free form/email service later (or a Google Form/Apps Script workflow).

Replace the temporary image crops with the original artwork files when you have them.
